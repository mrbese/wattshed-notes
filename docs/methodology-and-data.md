# Methodology and data

WattShed uses several calculation families so a program can inspect the same proposed upgrade through more than one lens:

- degree-day calculations
- modified-bin calculations
- deemed-measure tables where an applicable program pack covers the selected baseline

The public designer uses 3,143 county records and 30 TMY3 climate packs. These inputs support geographic and climate context. They do not turn a modeled result into a measured outcome.

The methodology offering varies by location. Degree-day and modified-bin estimates provide national coverage, while deemed-measure packs are offered where the selected state and baseline are supported. The current implementation includes a Texas TRM v13.0 pack. Where no applicable deemed pack exists, the product labels that constraint rather than inventing a deemed result.

Savings, demand relief, bill effects, costs, and program value are estimates produced from stated assumptions. They are not utility bills, engineering stamps, measurement-and-verification results, guaranteed savings, or a substitute for site-specific professional judgment.

The public methodology pages name sources and explain calculation assumptions in more detail. This note deliberately does not republish data files, proprietary implementation choices, or a copyable rulebook.
