# Product boundaries

WattShed designs and administers rebate-program workflows. It can produce a methodology-priced offer, help review evidence, clear defined milestones, and create auditable payment instructions.

WattShed does not lend, custody program funds, operate a payment processor, or claim to guarantee a homeowner's savings. The intended money path is direct from funder to contractor after the applicable approval and completion steps. The current settlement flow is simulated, not a live payment rail.

AI assistance is bounded. It can support inspection and evidence review, while deterministic logic controls qualification, savings figures, eligibility, and payout caps. A model is not permitted to overrule the calculation or authorize a disbursement.

The public no-login tools are useful for inspection and exploration. They are not an enrollment promise, a contractor marketplace, a utility tariff, a binding quote, or a commitment to run a program in every location.
